# Fingerpost promo video

A 40–50 s, 1920 × 1080, 60 fps promo built with Remotion. Design: `docs/superpowers/specs/2026-11-04-promo-video-design.md`; plan: `docs/superpowers/plans/2026-11-04-promo-video.md`.

## Preview and render

```bash
pnpm --filter @fingerpost/promo studio      # live preview at http://localhost:3418
pnpm --filter @fingerpost/promo render      # writes apps/promo/out/promo.mp4
```

Port 3417/3418 is used because another local app often holds Remotion's default port 3000.

## Music

1. Put the licensed track at `public/music/upbeat-rock.mp3` and record its source and licence in `public/music/LICENSE.md`.
2. Regenerate the beat grid (choose `--offset` so the reveal lands on a hit):
   `python3 scripts/promo_beats.py apps/promo/public/music/upbeat-rock.mp3 apps/promo/src/beats.json --offset 0`
3. Add `<Music />` (`src/music.tsx`) to `src/promo.tsx` and run `pnpm --filter @fingerpost/promo test`: every scene boundary must land on a beat and the music must fade out at the end.

Until then `src/beats.json` is a provisional 120 BPM grid (`"provisional": true`).

## Sounds

`public/sfx/` holds the guidance tones and buzz, generated by `python3 scripts/promo_tones.py apps/promo/public/sfx`.

## Copy rules

Lines that quote the app live in `src/copy.ts` as `appQuote` and are tested against `Strings.kt`. The kiosk is fictional and unbranded; the example total is 12.40.
