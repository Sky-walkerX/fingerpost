Security

  • Everything between the app and the server is encrypted in transit.
  • The app proves it is a genuine copy with Android Key Attestation before it may use the server.
  • No Fingerpost keys are stored on your phone.

Fingerpost is an assistive aid. Double-check important actions. Not for medical devices.
