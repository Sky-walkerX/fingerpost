Try the demo

Set up the Fingerpost demo

You need an Android 10+ phone, a laptop and a USB cable. The current hackathon APK connects to a gateway running on your laptop. The phone steps work with TalkBack.

This is a debug build for practice screens. Recognition and safety acceptance are still being tested. Do not use it for real payments.

Prepare your laptop first

Install Node 24, pnpm 11.10.0 and Android platform tools (adb). Set ANDROID_HOME to your Android SDK folder so the gateway can find platform-tools/adb. Download the Fingerpost source code and open a terminal in its folder. Enable USB debugging on your phone, connect it by USB and approve the debugging prompt.

Run pnpm install --frozen-lockfile, then pnpm dev:phone. Keep the command running; it connects the app to the laptop gateway over USB. This practice mode uses canned answers without an API key or model charges.

For real screen reading, add your Meta API key to a local .env file as META_API_KEY, then use pnpm dev:phone --live instead. Live requests use your Meta API credits. Keep the key private.

In another terminal, run pnpm --filter @fingerpost/web dev and open http://localhost:5173/kiosk/ on the laptop. Keep the practice kiosk fullscreen. The local development guide has more setup help.

Install and try it on your phone

  1. On your phone, open Chrome and go to the Fingerpost hackathon demo release. TalkBack reads the release title, then its notes.
  2. Swipe right until TalkBack reads fingerpost-hackathon-debug.apk. Double-tap it to download. Skip the file that ends in "sha256"; that one is for checking the download.
  3. When Chrome says the download is complete, double-tap "Open". If you missed it, open the Files app, go to Downloads and double-tap the Fingerpost file.
  4. If Android says Chrome isn't allowed to install apps, double-tap "Settings", turn on "Allow from this source", then go back with the Back gesture.
  5. Double-tap "Install". Review any Android security prompts and the release notes before deciding whether to continue. Wait until TalkBack announces that the app is installed, then double-tap "Open".
  6. Fingerpost starts with a short spoken tutorial. Listen to it all the way through the first time.
  7. When asked, allow the camera and the microphone. Fingerpost needs both: the camera to follow your finger and the screen, and the microphone to hear what you want to press.
  8. Keep the USB cable connected and the laptop gateway running. Point the phone at the practice kiosk. After the beep, say "I want to press start order". Fingerpost tells you how to move your finger and says "Press now" when you're on the button.

If something goes wrong

  • "App not installed": an older Fingerpost from a different source may be on the phone. Uninstall it, then install again.
  • No speech: check the media volume, and that a text-to-speech voice is installed in Android's accessibility settings.
  • Not connected: check the USB cable, approve USB debugging and make sure pnpm dev:phone is still running on the laptop.
  • No internet: Fingerpost switches to basic mode, which finds buttons that have words on them.

Updating

Check the release notes before installing another build. Updates signed with the same key keep your settings and saved screens; changing signing keys may require reinstalling.

Checking the download (optional)

Each release also has a "sha256" file. On a computer, run sha256sum on the downloaded app file; the result must equal the text in that file.
