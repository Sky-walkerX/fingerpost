Install Fingerpost on Android

These steps work with TalkBack. They take about five minutes. You need an Android phone with Android 10 or newer.

Fingerpost is a beta and isn't on Google Play yet, so you install it from its GitHub page. Android will warn you about apps from outside Play; the steps below say what to choose.

Steps

  1. On your phone, open Chrome and go to the latest Fingerpost release. TalkBack reads the release title, then its notes.
  2. Swipe right until TalkBack reads a file name that starts with "fingerpost" and ends in "apk". Double-tap it to download. Skip the file that ends in "sha256"; that one is for checking the download.
  3. When Chrome says the download is complete, double-tap "Open". If you missed it, open the Files app, go to Downloads and double-tap the Fingerpost file.
  4. If Android says Chrome isn't allowed to install apps, double-tap "Settings", turn on "Allow from this source", then go back with the Back gesture.
  5. Double-tap "Install". If Google Play Protect warns that it doesn't know the app, choose the option to install anyway. Wait until TalkBack announces that the app is installed, then double-tap "Open".
  6. Fingerpost starts with a short spoken tutorial. Listen to it all the way through the first time.
  7. When asked, allow the camera and the microphone. Fingerpost needs both: the camera to follow your finger and the screen, and the microphone to hear what you want to press.
  8. Hold the phone about an arm's length from a touchscreen, pointing straight at it, and say what you want to press, for example "Start". Fingerpost tells you how to move your finger and says "Tap" when you're on the button.

If something goes wrong

  • "App not installed": an older Fingerpost from a different source may be on the phone. Uninstall it, then install again.
  • No speech: check the media volume, and that a text-to-speech voice is installed in Android's accessibility settings.
  • No internet: Fingerpost switches to basic mode, which finds buttons that have words on them.

Updating

Repeat these steps with the newest release. Your settings and saved screens are kept.

Checking the download (optional)

Each release also has a "sha256" file. On a computer, run sha256sum on the downloaded app file; the result must equal the text in that file.

Fingerpost is an assistive aid. Double-check important actions. Not for medical devices.
