# Security policy

Report suspected vulnerabilities privately to the maintainers. Do not disclose
them in public issues, pull requests, or discussion threads.

The planned contact is `security@fingerpost.invalid`. This is a placeholder and
cannot receive mail; a working private reporting contact must be published before
the public beta. Until then, use an existing private channel with a maintainer.

Include the affected version, reproduction steps using synthetic data, and the
expected and observed behavior. Never include API keys, PINs, camera captures,
audio, transcripts, or other personal information.

Fingerpost is under development. There is no supported public release yet.

See [AGENTS.md](AGENTS.md) for the project's security requirements and
[ADR 0005](docs/adr/0005-zero-retention.md) for the zero-retention policy.
