It covers empty OCR, English/Hindi/Spanish PIN wording, non-PIN word continuations, a digit grid, blocking the first PIN frame, and failed OCR preventing premature resume.

Before changing production code, the physical phone reports **eight tests, zero passed, eight failed**: the first fails with `ExceptionInInitializerError`; the remaining checks fail with `NoClassDefFoundError` after initialization has failed.

## Reproducing the Android regression

With one authorized phone connected (keep device selectors private):

```sh
./scripts/android.sh :app:assembleDebug :app:assembleDebugAndroidTest --console=plain
adb -d install -r apps/android/app/build/outputs/apk/debug/app-debug.apk
adb -d install -r apps/android/app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -d shell am instrument -w io.github.fingerpost.test/io.github.fingerpost.DeviceSafetyRunner
```

The runner returns numeric `tests`, `passed`, `failed` fields, fixed test identifiers/exception types and instrumentation code -1 only on success. A successful safety regression does not establish camera, speech recognition, guidance-loop, thermal-performance or proxy-trial acceptance.
